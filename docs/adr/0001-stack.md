# ADR 0001 — Stack: standalone archetype defaults

Status: accepted · Date: 2026-11-10

The app starts from the Etzian standalone template: Rust + Tauri 2, Svelte 5 + TypeScript,
`@etzianco/ui`, Fluent, SQLite when it needs a database. Deviations from these defaults
are recorded as new ADRs in this folder, using `~/etzian/_foundation/tech/adr-template.md`.
